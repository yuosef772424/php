# صِفر

نموذج محادثة عربي صغير (نحو 14 مليون معامل) نبنيه بأيدينا خطوة خطوة: المقطِّع، والنموذج ومشتقاته، والتدريب، والتوليد. لا نستعمل أي إطار ذكاء اصطناعي جاهز مثل TensorFlow أو PyTorch، ونستعمل NumPy وCuPy للحساب فقط.

> «صِفر» اسم عمل، واسم المستودع سيتغير لاحقًا.

## الخطة

الخطة الكاملة، بأقسامها العشرين وسبب كل قرار وجدول متابعة التقدّم، في [`docs/plan.md`](docs/plan.md). هي نسخة من [مستند الخطة](https://claude.ai/artifact/LvK2dp6NBvzuKVhQsCXWZU) الذي نعدّل فيه الخطة (خاص بصاحب المستودع حتى يشاركه)، ونحدّث النسخة هنا بعد كل تعديل.

نعمل في ثلاث مراحل:

1. **التحقق (الأقسام 0–10):** نبني النموذج والمدرب ونختبرهما على بيانات إنجليزية جاهزة لها نتائج منشورة، Tiny Shakespeare ثم TinyStories. أغلب الأخطاء المتوقعة في طبقاتنا المكتوبة بأيدينا، والرقم المنشور يكشفها قبل أن تختلط بمشاكل البيانات.
2. **العربية (الأقسام 11–14):** نجمع النص العربي وننظفه، وندرّب المقطِّع عليه، ثم التدريب المسبق بالكود الذي ثبتت صحته.
3. **المحادثة (الأقسام 15–19):** قالب المحادثة وبيانات الحوار، والضبط الدقيق، والتوليد، والتقييم، ثم التحسينات الاختيارية.

## القواعد

- **ممنوع:** TensorFlow وPyTorch، وكل إطار يقدّم طبقات جاهزة أو اشتقاقًا تلقائيًا (مثل JAX وKeras وtransformers)، وأي أوزان مدرَّبة مسبقًا.
- **مسموح:** بايثون ومكتبتها القياسية، وNumPy وCuPy وmatplotlib وpytest.
- **نكتبه بأيدينا:** المقطِّع، وطبقات النموذج مع مشتقاتها، والمحسّن، وحلقة التدريب، والتوليد.

## البنية

| المجلد | القسم | ما فيه |
| --- | --- | --- |
| `sifr/core/` | 1 | الواجهة الخلفية (NumPy أو CuPy)، الإعدادات، البذور، البصمات، السجلات |
| `scripts/` | كل الأقسام | نقاط التشغيل، وأولها `check_env.py` |
| `docs/` | كل الأقسام | الخطة الكاملة ومخطط المراحل |
| `tests/` | 7 | الاختبارات (pytest) |

تُضاف بقية المجلدات مع أقسامها.

## التشغيل

```bash
pip install -r requirements.txt
python scripts/check_env.py   # الإصدارات، وهل يوجد GPU، وفحص حساب صغير
pytest -q                     # كل الاختبارات
```

على Colab مع GPU نحتاج CuPy أيضًا (قد تكون مثبتة مسبقًا): `pip install cupy-cuda12x`.

## اللغة في الكود

التعليقات والشروح بالعربية لأنها جزء من المحتوى التعليمي. أسماء الدوال ورسائل التشغيل بالإنجليزية، لأن كثيرًا من الطرفيات لا تعرض العربية من اليمين إلى اليسار بشكل صحيح.
